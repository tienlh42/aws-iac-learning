### EKS
- [ ] Dựng EKS bằng [learn-terraform-provision-eks-cluster](https://github.com/hashicorp-education/learn-terraform-provision-eks-cluster)
- [ ] Đọc [terraform-aws-modules/terraform-aws-eks](https://github.com/terraform-aws-modules/terraform-aws-eks)
